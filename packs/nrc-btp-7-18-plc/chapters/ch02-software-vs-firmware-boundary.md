# Chapter 2: Software versus firmware boundary

Sources: NUREG-0800 Branch Technical Position 7-18, Rev. 6, August 2016, ML16019A327. Listing-page title: "Guidance on the Use of Programmable Logic Controllers in Digital Computer-Based Instrumentation and Control Systems". PDF body was not captured. No page range.

## Core Idea

This pack draws a software versus firmware line as a question boundary. It does not copy a criterion from the unread BTP. Firmware, in this pack, means the embedded logic image on a PLC. Software, in this pack, means the life-cycle products that `nrc-nuclear` already reviews under BTP 7-14.

- Split labour. This chapter names the boundary question. It does not hold the BTP 7-14 method.
- Edition rule. The pin remains Rev. 6, August 2016, ML16019A327.

## Mental Models

Ask which object the question is about. An embedded logic image stays in this chapter as a question. A life-cycle plan, review, or design output leaves for `nrc-nuclear`.
