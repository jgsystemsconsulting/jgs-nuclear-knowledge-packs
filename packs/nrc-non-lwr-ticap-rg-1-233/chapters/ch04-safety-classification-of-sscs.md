# Chapter 4: Safety Classification of Structures, Systems, and Components

Sources: NRC RG 1.233 Rev 0, Guidance for a Technology-Inclusive, Risk-Informed, and Performance-Based Methodology to Inform the Licensing Basis and Content of Applications for Licenses, Certifications, and Approvals for Non-Light Water Reactors, June 2020, ML20091L698; verified via Federal Register notice 85 FR 35339 on 2026-11-13.

## Core Idea

Safety classification sorts structures, systems, and components (SSCs) into safety-related, non-safety-related with special treatment, and non-safety-related without special treatment. Classification follows the safety functions an SSC is credited for in the selected licensing basis events. Special treatment means the additional quality and reliability controls that follow from that classification. Classification therefore comes after event selection, not before it: the events define which functions matter, and the functions define how SSCs sort. No performance criterion, reliability target, or capability value for any class is stated in this pack. No equipment is classified here and no plant component question is answered.

## Frameworks Introduced

- Three-family classification. Safety-related, non-safety-related with special treatment, and non-safety-related without special treatment name the classification families at definition depth.
- Function-driven boundaries. The safety function credited in selected licensing basis events drives where an SSC sits; equipment labels alone do not.
- Special treatment as follow-on controls. Special treatment means additional quality and reliability controls that attach after classification, not a free-standing equipment list.
- Sequence discipline. Event selection precedes classification; reversing the order severs the function link the method relies on.

## Key Concepts

- Structure, system, or component (SSC): plant hardware or system element the classification stage sorts by credited safety function.
- Safety-related: classification family for SSCs credited for safety functions in the selected licensing basis events at the safety-related depth the method uses; no performance value packaged here.
- Non-safety-related with special treatment: classification family for SSCs that are not safety-related yet still receive additional quality and reliability controls.
- Non-safety-related without special treatment: classification family for SSCs outside both safety-related and special-treatment scopes.
- Special treatment: additional quality and reliability controls that follow from classification; not a numeric reliability target and not a packaged capability value.
- Credited safety function: the function an SSC is relied on to perform in selected licensing basis events; that credit drives classification boundaries.
- Classification after selection: SSC class follows the event set already selected; classification does not invent the event set.
- Fence: no performance criterion, reliability target, or capability value for any class is stated in this pack.

## Mental Models

Picture a tag attached after the event sorter finishes. Each SSC receives a tag based on the safety function it is credited for in the selected events: safety-related, non-safety-related with special treatment, or non-safety-related without special treatment. Special treatment is the control package that rides with the middle tag, not a separate scoring system. Tag the functions the events already named; do not invent classes from equipment catalogs that ignore those events.

## Anti-patterns

Classifying SSCs before licensing basis events are selected is the named anti-pattern: without credited functions from selected events, class boundaries float free of the method. A companion error is treating special treatment as a numeric reliability or capability target rather than as quality and reliability controls that follow classification. A third error is classifying named plant equipment from this chapter or answering which class a real component must carry. A fourth error is stating performance criteria or reliability values for any class; none are packaged here.

## Key Takeaways

- Safety classification sorts SSCs into safety-related, non-safety-related with special treatment, and non-safety-related without special treatment.
- Boundaries follow the safety functions credited in the selected licensing basis events.
- Special treatment means additional quality and reliability controls that follow from classification.
- Classification follows event selection; it does not precede it.
- No performance criterion, reliability target, or capability value is stated, and no equipment is classified in this pack.
