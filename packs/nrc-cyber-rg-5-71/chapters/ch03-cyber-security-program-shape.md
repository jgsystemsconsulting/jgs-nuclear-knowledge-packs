# Chapter 3: Cyber security program shape

Sources: NRC RG 5.71 Rev. 1, Cyber Security Programs for Nuclear Power Reactors, February 2023, ML22258A204; pin 2026-11-08 (P9 VERIFY cleared).

## Core Idea

The cyber security program RG 5.71 describes is graded and uses a defense-in-depth approach. At orientation level: the program's defensive controls are named in this pack as categories only, and the program's elements run from establishing and implementing the program to monitoring, sustaining, and reassessing it. That shape statement is the chapter's whole load; the guide's own text carries the method detail.

## Frameworks Introduced

- A graded, defense-in-depth program. The program is graded and uses a defense-in-depth approach; ch04 orients the defensive architecture that phrase points at.
- Program elements as lifecycle stages. Establishing, implementing, monitoring, sustaining, and reassessing the program are its lifecycle elements; ch06 orients them at framework level.

## Key Concepts

- Graded approach: the program is graded; this pack states the grade word and no scheme detail.
- Defense-in-depth: the approach the program uses; layers are ch04's subject.
- Defensive controls as categories only: program controls are named as categories, never products, configurations, detection logic, or tuning.
- Lifecycle elements: establishing, implementing, monitoring, sustaining, and reassessing the program.

## Mental Models

Read the program shape as three words in order: graded, layered, lifecycle. The program is graded; the grade scheme stays in the guide, and lifecycle in how it is run over time. Anything past those words, in any direction, belongs to the guide and the regulation.

## Anti-patterns

Treating category names as implementation guidance is the chapter's named anti-pattern. No product, configuration, detection-logic, or tuning guidance appears in this pack; a category name locates a topic, it does not tell anyone how to build, buy, configure, or tune anything.
