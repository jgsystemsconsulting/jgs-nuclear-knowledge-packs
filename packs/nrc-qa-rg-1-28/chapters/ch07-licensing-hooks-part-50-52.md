# Chapter 7: Licensing hooks in Part 50 and Part 52

Sources: NRC RG 1.28 Rev 6, September 2023, ML23177A002 (Federal Register notice 2023-19548); 10 CFR Parts 50 and 52 for the licensing hooks; pin 2026-11-08.

## Core Idea

The guide's criteria reach into licensing through 10 CFR Parts 50 and 52. Section 50.34 requires the quality assurance program description in both safety analysis report stages, and 50.54(a) makes implementing that program a standing license condition. Part 52 applications carry the equivalent descriptions. Appendix B applies to activities affecting the safety-related functions of the covered structures, systems, and components, and RG 1.28 Rev 6 describes an acceptable way to meet those criteria. The Part 50 sections behind these hooks are oriented in the Part 50 licensing basis pack; this chapter carries the hooks this pack's reader needs.

## Frameworks Introduced

- Description in the application. The quality assurance program description is application content: 50.34 places it in both the preliminary and final safety analysis report stages, and Part 52 applications carry the equivalent descriptions.
- Standing condition. Implementing the described program is not a one-time submission event: 50.54(a) makes it a standing license condition.

## Key Concepts

- 50.34: the quality assurance program description is required in both safety analysis report stages.
- 50.54(a): implementing the program is a standing license condition.
- Part 52: applications under it carry the equivalent quality assurance descriptions.
- Appendix B's reach: it applies to activities affecting the safety-related functions of the covered structures, systems, and components.
- The guide's role in the chain: RG 1.28 Rev 6 describes an acceptable way to meet the Appendix B criteria that the application describes and the license condition keeps standing.

## Mental Models

From guide to license: the guide describes an acceptable program path, the applicant describes its program in the safety analysis report (or the Part 52 equivalent), and the license condition keeps the program standing after issuance. A question lands on one link of that chain, and this chapter names where each link lives.

## Anti-patterns

Treating this chapter as quality assurance program advice is the named anti-pattern: the chapter states where descriptions and conditions live, not what any plant's program should contain. Reading the hooks as one-time filing events misses the standing-condition character of 50.54(a).

## Key Takeaways

- The quality assurance program description enters through 50.34 in both safety analysis report stages, with Part 52 equivalents.
- 50.54(a) makes implementing the program a standing license condition.
- Appendix B applies to activities affecting safety-related functions, and the guide serves those criteria.
