# Glossary: nrc-pra-adequacy-rg-1-200

Synthesized orientation definitions keyed to the pack closed statements and the RG 1.200 Rev. 3 pin, alphabetical, not a substitute for source text.

- **acceptability**: the guide-side question of whether PRA results may be relied on to support a risk-informed activity. In this pack it names the subject RG 1.200 addresses, never a verdict the pack issues. (ch01)
- **application**: the named use a PRA supports: the risk-informed activity and the decision the PRA results would inform. Adequacy is judged against the application, so an answer names it first. (ch01, ch02)
- **core damage frequency**: spelled out, CDF: a risk metric name. A metric name in this pack only; no value is stated and no computation is described. (ch05)
- **defense-in-depth**: a non-PRA consideration weighed alongside PRA results in an integrated risk-informed decision. This pack carries the weighing statement, not any plant-specific judgement. (ch05)
- **endorsed standard**: the standard the guide names as endorsed; the RG 1.200 Rev. 3 designation on record is ASME/ANS RA-Sa-2009 (Addendum A). Designation and endorsement fact only here; standard text is never packaged. (ch03)
- **large early release frequency**: spelled out, LERF: a risk metric name. A metric name in this pack only; no value is stated and no computation is described. (ch05)
- **listing-page pin**: the date-stamped pointer the pack carries to the guide listing: NRC RG 1.200 Rev. 3, December 2020, accession ML20238B871; listing-page 2026-11-08, re-checked 2026-11-11. Verify against the current guide listing before relying on it. (ch01)
- **PRA adequacy**: whether the PRA behind a risk-informed use is technically adequate for the named application. The RG 1.200 pack orients the question and carries no adequacy criteria. (ch01, ch02)
- **probabilistic risk assessment**: the analysis whose results a risk-informed activity leans on and whose adequacy for the application is the question here. This pack carries no instruction on building, updating, or quantifying one. (ch01)
- **regulatory guide**: an NRC document describing one method the staff finds acceptable. Guidance, not regulation; the text binds no licensee through this pack. (ch01)
- **risk-informed activity**: an activity or decision that uses PRA results as an input, weighed alongside non-PRA considerations. The class of use whose supporting PRA adequacy RG 1.200 addresses. (ch01, ch05)
- **safety margins**: a non-PRA consideration weighed alongside PRA results in an integrated risk-informed decision. This pack carries the weighing statement, not any plant-specific judgement. (ch05)
- **treatment of uncertainty**: the named companion consideration standing behind a risk-informed decision, alongside the PRA technical adequacy for the application. Its guidance home is named in ch06; no uncertainty methods are packaged here. (ch05, ch06)
